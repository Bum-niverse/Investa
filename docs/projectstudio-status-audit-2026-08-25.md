# ProjectStudio 구현 상태 정합성 감사

기준일: 2026-08-25

최종 반영: ProjectStudio PRD revision 102 · 기능 234개 중 완료 193개, 진행 중 35개, 계획 6개.

최근 반영 전 자동 백업: `projectstudio-before-api-20260825-130642-86fb709d.db`

## revision 102 보완

- 연결·계좌 설정의 시장·뉴스·증권사·거래소·AI 영역을 키보드 조작 가능한 접기·펼치기 섹션으로 구현한 근거를 기능명세에 반영했다.
- 분석 보관소의 시장 분류에 증권 선물과 코인 선물을 추가하고, 기존 분석 기록을 보존하는 SQLite v21 마이그레이션과 자산 계약별 예측 필터 검증을 완료 기준에 반영했다.

## 2차 노드 감사

- 44인 전체 로스터와 직접 보고 관계가 이미 구현되어 있어 중간 단계인 27인 MVP 기준도 충족으로 바로잡았다.
- Telegram 사용자 인증·허용 채널 경계, 재시작 체크포인트 기반 안전 재실행, 원본 실험과 분리된 OOS 검증 결과 저장을 구현 근거에 맞게 체크했다.
- 계정 연결 묶음의 OS 보안 저장소·실전 잠금, SEC 연락처 설정, NASDAQ 전광판의 지연·미연결 상태, 공식 뉴스·커뮤니티 정규화 계약, 선물의 내부 sandbox 경계, 예측 결과의 불변 추적 계약은 해당 하위 기준만 체크했다.
- 외부 계정 왕복, 공급자·라이선스 선정, 24시간 soak, 실제 App Server 장시간 반복 검수는 완료로 올리지 않았다.

## 승인 불필요 묶음 개발 반영

- 이번 요청의 실제 작업용 말단 노드 26개 중 17개를 추가 완료했다.
- 완료 근거에는 워크스페이스 시작 잠금, 시장 주문 단위 어댑터, 제한 재시도, 뉴스·커뮤니티 구조화, 근거 추적, 직원 패널, 코인 현물, 홍보 근거·초안·미디어·수동 게시 패키지, 청산 사유, Walk-forward 상태모형, 관측 시각 대시보드와 원장 기반 통화별 포트폴리오 위험 화면이 포함된다.
- 후속 5개 묶음에서 알림·킬 스위치 운영자와 대표 승인·게시 준비 노드를 추가 완료해 이 묶음에서 남은 말단 노드는 6개다. 구현한 soak 감사기와 24시간 합성 재생만으로 실제 24시간 무중복을 완료 처리하지 않았고, 장시간 App Server 반복 검수와 공식 캘린더도 실제 근거 없이 체크하지 않았다.

## 판정 원칙

- `done`: 코드 경로와 검증 근거가 있고 모든 수용 기준이 충족된 경우만 사용한다.
- `in_progress`: 기반 계약이나 일부 동작은 구현됐지만 UI, 장시간 검수, 외부 대사 또는 전용 엔진이 남은 경우다.
- `planned`: 계정, 유료·라이선스 공급자, 모델 설치, 외부 왕복 또는 아직 작성하지 않은 기능이다.
- 역할별 Codex 정책과 `RoleReport` 계약이 실제로 있는 직원은 해당 역할의 소견 생성 기준을 완료로 판정한다. 계좌 조회·주문·24시간 감시처럼 Codex 답변만으로 충족할 수 없는 기준은 별도로 남긴다.

## 이번에 바로잡은 항목

- 완료 기준 3/3이던 `백테스트와 검증 연구실`을 완료로 변경했다.
- 44인 로스터, 역할 정책, 직접 보고 관계와 역할 한정 응답 계약을 조직·직원 노드에 반영했다.
- 레퍼런스·기획·디자인·Codex 로컬 연결 결정 기록은 이미 PRD와 구현 근거가 있어 완료로 변경했다.
- 토스증권 계좌 잔고 UI 노드를 주문 실행 대분류에서 브로커 대분류로 옮겼다.
- 모든 기능 `sortOrder`를 트리 순서의 고유 값으로 재배치했다.
- PRD에 반복되던 20·21·23번과 번호 없는 2단계 제목을 현재 순서대로 다시 번호 매겼다.
- 완료된 회의 위험 판정·후보 등록, 원격 명령 검증, 연구실 진입 유저플로 체크를 반영했다.

## 남은 개발 분류

### 계정 없이 바로 개발 가능

- 운영 DB 실제 복원 전 승인·원자 교체·롤백 흐름
- 일반 사용자용 로그인 정책·OAuth 서버 경계 설계

### 이번 추가 구현으로 닫은 항목

- 모의원장·시점 정합 시세를 이용한 손실·낙폭·연속 손실·종목·섹터·시장 노출 계산과 `continue/reduce/stop` 권고
- 중복 주문·멱등 키·과다 수량·부분체결·실행손실·비용·지연 분리 및 신규 주문 일시정지 후보 판정
- 코인 레버리지 1~2배 상한, 정확한 위험 확인, 정책 리비전·사유의 불변 이력 저장
- 전략 잠금 시작·해제 알림의 멱등 기록과 잠금 중 신규 진입 차단·감축·취소 허용
- 선물 일일정산 변동증거금, 만기 청산, 수동 롤오버의 append-only 사건 계약과 자동 연장 금지
- 브로커 자격정보·IP 권한·호출 한도·점검 상태의 오류 분류
- 여섯 운영 장애 시나리오의 격리 훈련, 신규 진입 차단·취소 허용 판정과 SQLite 훈련·알림 이력
- 홍보 원고 리비전 저장, 수정 시 승인 무효화, 서버가 최신 승인·마스킹을 재확인하는 수동 게시 패키지
- 중단 회의 부분 보고 보존·안전 재실행 프론트 회귀 테스트와 24시간 합성 타임라인 내구 재생

### 외부 계정·자격정보가 있어야 끝나는 작업

- KIS 모의 잔고·주문·취소·체결·재시작 대사의 실제 왕복 검증
- Toss 장시간 세션 만료·rate limit·오류 복구 검증
- Upbit·Binance 개인계좌 잔고·포지션 읽기 전용 검증
- Telegram Bot 송수신, Google Cloud relay·Secret Manager·비용 상한과 결과 회신
- SEC 실제 연락처와 여러 미국 종목의 재무·공시 검수

### 공급자·라이선스 결정이 필요한 작업

- NASDAQ 공식 지수 피드
- 일반 뉴스와 커뮤니티 공식 API
- 국내 선물 공식 상품 마스터·실시간 시세

### 모델 설치·연구 승인이 필요한 작업

- Chronos·TimesFM 외부 Python worker와 모델 가중치
- 자산군·horizon별 OOS 보정, 순진 기준선 비교와 모델 승격 판단

### 의도적으로 계속 잠근 작업

- 실전 주문 전송과 출금
- 모의·실전 자격정보 혼용

- 자동 티스토리 발행
