# Investa 연결 어댑터 가이드

Investa 배포판은 계좌번호 하나로 모든 금융회사를 연결한다고 가정하지 않습니다. 증권사·거래소·AI 공급자마다 인증, 계좌 식별자, 시세 권한과 주문 규격이 다르므로 공식 API별 어댑터를 추가해야 합니다.

## 현재 기본 제공 범위

| 공급자 | 시장 | 기능 | 상태 |

KIS는 기존 모의·국내선물 코드를 보존하지만 현재 공급자 선정·연결 범위에서는 제외한다. 실제 계정과 공식 왕복이 준비되기 전에는 연결 완료로 계산하지 않는다. 시장·뉴스·커뮤니티 공급자 결정은 [외부 데이터·AI 공급자 선정](provider-selection-2026-08-27.md)을 따른다.

## 어댑터 계약

새 공급자는 `src/integrationCatalog.ts`에 표시 정의를 추가하고 Rust 백엔드에 다음 경계를 구현합니다.

1. `config_status`: 비밀값을 반환하지 않고 설정·연결 여부와 마스킹 식별자만 반환합니다.
2. `config_save`: 공급자 입력을 엄격히 검증하고 연결 확인 후 운영체제 자격 증명 저장소에 보관합니다.
3. `config_delete`: 해당 공급자의 로컬 자격정보만 명시적으로 삭제합니다.
4. `account_snapshot`: 최소 계좌·잔고 DTO만 반환하고 원본 공급자 응답과 내부 계좌 식별자를 노출하지 않습니다.
5. `market_snapshot`: 공급자, 관측 시각, 통화와 데이터 지연 여부를 함께 반환합니다.
6. `paper_order`: 모의 서버가 있는 공급자에만 구현하고 멱등성 키·수량·가격·시장·계좌 소유권을 다시 검증합니다.
7. `live_order`: 기본 계약에는 포함하지 않습니다. 별도 위험 검토와 명시적 사용자 승인 없이는 추가하지 않습니다.

## 보안 규칙

- API Key, Secret, OAuth token, 계좌번호 전체를 소스, `.env.example`, SQLite, 로그, 오류 메시지에 넣지 않습니다.
- React에는 비밀값을 저장하지 않고 입력 순간에만 유지합니다.
- Windows 배포판은 자격정보를 Windows 자격 증명 관리자에 저장합니다.
- AI 어댑터에는 증권사·거래소 자격정보와 주문 함수를 전달하지 않습니다.
- Claude·Antigravity API 구독·쿼터는 ChatGPT·Claude·Google AI Pro 소비자 구독과 별도일 수 있으므로 키 저장만으로 연결 검사를 호출하지 않습니다.
- Antigravity에는 코드 실행·원격 파일·custom function·MCP를 제공하지 않고 검색·URL 근거 읽기만 허용합니다.
- 공급자 API 응답은 신뢰할 수 없는 외부 입력으로 취급하고 타입·길이·통화·단위·관측 시각을 검증합니다.
- 공식 API가 없는 공급자를 브라우저 자동화나 비공식 역공학으로 우회 연결하지 않습니다.
- Upbit 키에는 자산조회 권한만 부여하고 주문·출금 권한은 부여하지 않습니다. 연결 확인 요청에는 매번 새로운 nonce를 사용합니다.
- Binance 키에는 계좌 읽기 권한만 사용하고 현물 거래, 선물 거래와 출금 권한을 활성화하지 않습니다. 현물·USDⓈ-M·COIN-M은 각각 다른 공식 서버 시각과 서명된 계좌 API로 검사하고, 일부 상품만 활성화된 경우에도 상품별 상태를 따로 표시합니다.
- 저장소 공개 전 Gitleaks 또는 GitHub Secret Scanning으로 현재 파일과 Git 이력을 함께 검사합니다.
- Rust 의존성은 RustSec `cargo audit`로 알려진 취약점을 검사하고, `cargo-deny` 도입 시 라이선스와 출처 정책을 별도로 고정합니다.

## 선물 계좌 구분

선물 계좌는 `증권 선물`과 `코인 선물`로 구분합니다. 증권사 어댑터는 국내 선물옵션, 해외선물과 내부 sandbox를 별도 시장으로 취급합니다. 한국투자증권 기준 국내 선물옵션은 상품코드 `03`, 해외선물은 별도 상품코드 `08` 계좌가 필요합니다. 코인 선물은 Binance 같은 파생상품 지원 거래소 계정을 사용하며 USDⓈ-M과 COIN-M의 증거금·잔고·포지션을 분리합니다.

KIS 국내선물 분석 어댑터는 공식 모의 서버의 `inquire-daily-fuopchartprice`를 읽기 전용으로 호출합니다. 사용자가 현재 만기 계약코드를 직접 입력해야 하며 근월물이나 연속선물을 임의 추정하지 않습니다. 공식 일봉 응답에 별도 정산가가 없으므로 종가를 정산가로 대체하지 않고 `결측`으로 보존합니다. 실제 왕복은 KIS 모의 App Key·Secret이 준비된 환경에서 별도 확인합니다.

## 연결 계정 생명주기

- 최초 검증 계정은 주 소유자로 고정하고 자동 이전하지 않습니다.
- 인증된 소유자 세션은 주 소유자가 아닌 연결 공급자를 `공급자명 연결 해제` 확인 문구 뒤 해제할 수 있습니다.
- 연결 해제는 SQLite 분석·백테스트·모의원장, 차트 선, 감사 기록과 백업을 삭제하지 않습니다.
- 복구는 이미 연결된 공급자 계정의 재인증만 허용합니다. 이메일 문자열이나 지원자 판단만으로 소유권을 우회하지 않습니다.
- 작업공간 전체 삭제는 소유자 재인증, 안전 백업, 보안 저장소 항목과 로컬 백업 삭제 범위가 구현되기 전까지 비활성화합니다.

## 사용자 전략과 AI

공개 저장소에는 사용자의 전략 파일과 모델 자격정보를 포함하지 않습니다. Codex는 사용자의 로컬 CLI 로그인 상태를 사용합니다. Claude와 Google Antigravity는 공통 분석 전용 REST 어댑터, Windows 자격 증명 저장, 동일한 `RoleReport`·`DepartmentReport` 검증, 직원별 작업 상태·취소와 승인형 부서 집계를 구현했습니다. 토큰 단위 실시간 스트리밍은 구현하지 않았고 단계별 상태 이벤트만 제공합니다. 실제 사용자 API 키 왕복 전까지 연결 상태는 `partial`을 유지합니다.

Google 계정 로그인은 Investa 사용자 식별용 OIDC이며 Gemini API 사용 권한이 아닙니다. Google AI Pro 소비자 구독도 Gemini Developer API의 인증·과금 권한을 자동 부여하지 않습니다. Antigravity 직원은 Google AI Studio에서 발급한 Gemini API 인증키를 Windows 자격 증명 관리자에 별도 저장해 호출하며, 로그인 access/refresh token을 재사용하거나 SQLite에 보존하지 않습니다.
