# 예측 기반시설 사이클 13~15

## 범위

이번 사이클은 머신러닝 모델을 학습하거나 투자 확률을 생성하지 않는다. 모델이 나중에 연결됐을 때 데이터와 결과를 재현하고 잘못된 확률을 차단하기 위한 기반만 구현한다.

## 사이클 13 · 시점 정합 데이터 품질 감사

- 자산 계약과 `datasetId`를 함께 검증한다.
- train·validation·test 구간의 시간순 분리를 확인한다.
- 결정 시각 이후에 이용 가능해진 피처를 누수로 차단한다.
- sample×feature N:N 중복과 피처가 없는 표본을 탐지한다.
- 필수 피처 누락, 기업행사 반영, 휴장·거래중단·세션 경계, 상장 초기 이력을 명시적으로 확인한다.
- 원시 가격·뉴스 본문은 감사 테이블에 복제하지 않고 계약과 검증 요약만 불변 저장한다.

## 사이클 14 · 확률 결과 불변 저장

- `forecastId`, `modelId`, `modelVersion`, `datasetId`, `assetContractId`, `horizonMs`를 필수 식별자로 사용한다.
- 방향 확률, 추천 확신도와 모델 신뢰도를 서로 다른 값으로 보존한다.
- 같은 식별자와 같은 내용의 재요청은 멱등 처리하고, 같은 식별자의 다른 내용은 거부한다.
- 품질 감사에 실패한 데이터셋은 숫자 확률을 저장할 수 없다.
- 분석 화면에서 모델·데이터셋·자산 계약·예측 기간과 최신 자산군별 보정 결과를 재조회한다.

## 사이클 15 · 자산군별 보정과 뉴스 누락 fallback

- 보정은 자산군·모델·모델 버전·데이터셋·horizon이 모두 일치하는 저장 예측만 대상으로 한다.
- Brier score, Log Loss, ECE와 표본 수를 정수 스케일로 저장한다.
- 국장, 미장, 증권 선물, 코인 현물, 코인 선물의 성과를 서로의 근거로 재사용하지 않는다.
- 뉴스 피처가 없고 가격 피처가 있을 때는 `price_only_fallback`을 반드시 표시한다.
- 가격 피처도 없으면 확률·확신도·신뢰도를 비우고 산출 불가 이유만 기록한다.

## 안전 경계

- 이 기반은 실주문 또는 내부 모의주문 권한을 부여하지 않는다.
- 모델이 연결되지 않은 상태에서는 확률을 임의 생성하지 않는다.
- IPC 입력은 표본 20,000개, 피처 200,000개, 보정 관측 20,000개로 제한한다.
- 계좌번호, API 키, 뉴스 원문과 개인정보는 예측 감사·결과 테이블에 저장하지 않는다.

## 외부 모델 연결 시 다음 조건

1. 모델 실행 전 데이터셋 감사를 저장한다.
2. 감사에 통과한 동일 `datasetId`와 자산 계약으로만 숫자 확률을 저장한다.
3. 자산군별 OOS 관측값으로 보정을 별도 실행한다.
4. 분석 화면에서 식별자와 fallback 여부를 확인한다.
5. 모의운영 승격은 별도의 결정론적 안전 게이트와 사용자 승인을 거친다.
