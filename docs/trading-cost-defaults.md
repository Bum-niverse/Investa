# 시장별 모의거래 비용 기본값

기준 확인일: 2026-08-22

Investa의 비용 기본값은 실제 수익이나 체결을 보장하는 값이 아니라 모의체결의 시작점이다. 수동 모의주문, 토스 주식 연구 백테스트와 승인형 내부 주식 체결에 같은 시장 기본값을 적용한다. 주문 화면에서는 언제든 변경할 수 있고 시장을 바꾸면 해당 시장의 공식 기본값으로 다시 설정된다. 계산 엔진은 기존 JSON 필드명을 유지하면서 `0.001bp` 단위까지 결정론적 정수 연산으로 환산한다.

## 기본값

| 시장 | 매수 수수료 | 매도 수수료 | 매도 세금·제비용 | 슬리피지 |
| --- | ---: | ---: | ---: | ---: |
| 국장 KRX | 1.5bp (0.015%) | 1.5bp (0.015%) | 20bp (0.20%) | 0bp |
| 미장 | 10bp (0.10%) | 10bp (0.10%) | 0.206bp (0.00206%) | 0bp |
| Upbit KRW | 5bp (0.05%) | 5bp (0.05%) | 0bp | 0bp |

## 적용 근거와 예외

### 국장

- 토스증권 Open API 공식 안내의 국내주식 KRX 수수료 `0.015%`를 기본값으로 사용한다.
- NXT 체결은 공식 안내상 `0.014%`이므로 NXT를 가정할 때 사용자가 `1.4bp`로 바꿀 수 있다. 현재 모의 시세 응답만으로 실제 체결 시장을 확정하지 않으므로 KRX를 보수적인 기본값으로 둔다.
- 한국투자증권 공식 매매관련 세금표의 KOSPI·KOSDAQ 매도 합계 `0.20%`를 적용한다. ETF·ETN·코넥스·K-OTC 등 상품·시장별 세율은 다르므로 현재 일반 주식 기본값을 그대로 쓰면 안 된다.

### 미장

- 토스증권 Open API 공식 안내의 미국주식 수수료 `0.1%`를 매수·매도 기본값으로 사용한다.
- 주문 건별 총 체결금액이 10달러 이하인 토스 주문은 공식 안내상 수수료가 없지만, 현재 로컬 모의원장은 주문별 프로모션·면제 자격을 확인하지 못하므로 기본 요율을 먼저 보여주고 사용자가 `0bp`로 변경할 수 있게 한다.
- 한국투자증권 공식 해외주식 비용표의 미국주식 매도 SEC Fee `0.00206%`를 매도 제비용 기본값으로 사용한다. 규제기관 요율은 변경될 수 있으며 ADR 보관료, 종목별 TAF, 환전 비용과 해외주식 양도소득세는 주문 한 건의 정률 체결비용으로 단순 합산하지 않는다.

### 코인

- Upbit 공식 전략 툴킷의 한국 KRW 마켓 수수료 예시 `0.05%`를 매수·매도 기본값으로 사용한다.
- 이벤트, 주문 방식과 회원별 실제 적용 요율이 다르면 주문 전에 공식 거래소 화면을 확인해 수정한다.
- 출금 수수료와 코인빌리기 수수료는 현물 매매수수료가 아니므로 포함하지 않는다.

### 슬리피지

슬리피지는 증권사나 거래소가 고정 비율로 부과하는 수수료가 아니다. 주문 크기, 스프레드, 호가 잔량, 변동성, 거래 시간과 주문 유형에 따라 달라지므로 공식 고정 기본값을 만들지 않고 `0bp`에서 시작한다. 백테스트와 모의운영에서는 전략·시장별 스트레스 값을 사용자가 별도로 입력한다.
