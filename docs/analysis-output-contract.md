# 투자 분석 출력 계약과 현재 충족 상태

기준일: 2026-09-04

## 목적

보유종목 또는 포트폴리오 분석 결과는 결론 문장만 저장하지 않는다. 분석 당시의 익명화 보유자산, point-in-time 가격봉, 기술지표, 출처, 근거 공백과 종목별 차트 주석을 같은 불변 기록에서 재현할 수 있어야 한다. 근거 충족도는 상승 확률이나 모델 신뢰도가 아니며, 보고를 작성한 부서의 근거 품질 자체평가다.

## 근거 충족도 표시

- 부서가 반환한 `confidencePercent`는 그대로 보존하되 화면에서는 `부서 자체평가`로 명시한다.
- 같은 패널에 고유 근거 ID 수, 근거가 있는 직원 수와 근거 공백이 남은 직원 수를 함께 표시한다.
- 점수를 문장 길이, 직원 점수 평균 또는 시장 방향 확률로 해석하지 않는다.
- 공식성·최신성·독립 교차검증·시점 정합성이 부족하면 80% 이상으로 올리지 않는다.

## 실행 시점 근거 가용성

- 전체 분석의 기술·재무·뉴스 담당은 각각 가격·기술, 재무·공시, 일반 뉴스·Telegram 최소 도구를 자동으로 실행한다. Agent가 선택하는 것은 이 필수 묶음 밖의 추가 조사다.
- 부서장에게는 직원 문장과 별도로 프로그램이 계산한 가용성 매니페스트를 전달한다. 유한 MACD·Bollinger 값, 지지·저항·추세선·가격 범위 주석, 재무·공시·뉴스·Telegram 건수가 1개 이상이면 다른 직원의 역할 밖 결측 주장으로 이를 지울 수 없다.
- 공급자 계약은 실제 `provider`별로 판정한다. `TOSS_OPEN_API` 자료에 KIS 고유 계약을 요구하지 않으며 KIS 자료일 때만 KIS 계약 상태를 확인한다.
- 신규 상장처럼 완료 봉이 실제로 부족하거나 공식 공급자가 0건을 반환한 항목은 계속 명시적 결측으로 보존한다.

## 포트폴리오·차트 저장

- 전체 회의뿐 아니라 승인형 부서 종합에도 동일 `SnapshotContext`를 전달한다.
- 보유종목 요청이면 계좌 조회가 실패해도 포트폴리오 영역을 숨기지 않고 결측 사유를 저장한다.
- 종목별 차트는 최대 120개 완료 봉과 계산된 주석·지표를 저장한다.
- 과거 기록은 append-only이므로 현재 계좌값으로 소급 덮어쓰지 않는다. 수정 이후 새 분석부터 완전한 시각 자료가 저장된다.

## 장문 보고와 단계형 종합

- 글자 수를 무제한으로 열어 한 요청에 모든 원문을 중복 삽입하지 않는다. 직원 `RoleReport`와 전체 `DepartmentReport`는 로컬 분석 기록에 원문으로 보존한다.
- 본부장 입력은 `직원 독립 보고 → 부서 보고 → 본부장 종합` 단계로 구성하고, 직원 근거는 `evidenceId` 기준으로 중복 제거한다. 같은 근거를 사용한 직원 목록은 유지한다.
- 본부장 프롬프트는 48,000자 하드 상한보다 4,000자 작은 예산으로 조립한다. 발생 근거 수, 고유 수, 포함·제외 수와 최종 입력 문자 수를 `synthesisTrace`에 저장해 생략을 숨기지 않는다.
- 길이 초과, 제한시간 또는 구조화 계약 검증으로 최종 종합이 실패해도 완료된 부서 보고와 실패 이유를 `hold` 분석 기록에 저장한다. 부분 결과를 한 줄 오류로 대체하지 않는다.
- 화면 스트리밍 안전 한도와 최종 구조화 보고 저장은 별개다. 최종 보고의 상세 내용은 구조화 계약 필드와 부서별 원문에서 확인하며, 외부 모델의 유한 문맥 한계를 무제한 출력으로 우회하지 않는다.

## 보안·데이터 경계

- 계좌번호·별칭·자격정보·Telegram 사용자 ID는 분석 기록과 AI 프롬프트에서 제외한다.
- 서로 다른 통화는 환율 근거 없이 합산하지 않는다.
- 차트는 실제 OHLCV만 사용하고 미래 가격 경로를 사실처럼 생성하지 않는다.
- 차트 주석은 관측 설명이며 주문 신호가 아니다. 실제 주문은 계속 잠긴다.

## 외부 뉴스·공시 출처 표시

- 분석 기록의 `evidenceSources`는 Naver 뉴스, Telegram 선택 채널과 OpenDART 공시의 출처 계보를 저장한다.
- 공통 필드는 `evidenceId`, `provider`, `medium`, `sourceName`, `title`, `publishedAt`, `observedAtMs`, `cited`다. URL은 공급자가 실제 제공하거나 검증 가능한 공개 URL만 저장한다.
- Naver 뉴스는 언론사 원문 URL과 Naver 검색 URL을 구분한다. Telegram은 공개 채널 링크만 제공하고 비공개 채널은 채널명과 관측 시각만 표시한다.
- `cited=true`는 저장된 직원·부서·본부장 보고의 `evidenceId`에 실제 등장한 경우에만 설정한다. 후보 수와 조회 수는 인용 수와 별개다.
